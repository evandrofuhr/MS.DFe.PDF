# Liberation Serif

Fontes [Liberation Serif](https://github.com/liberationfonts/liberation-fonts) 2.1.5 (SIL Open Font License),
métrica-compatíveis com Times New Roman.

Registradas em runtime pelo `FontesDFe` sob o nome `"Times New Roman"` para o QuestPDF
funcionar em Linux/Docker sem depender das fontes do sistema.
